# Goenvi Premium Deck Skill

This is not a template pack or a theme. It's a discipline for two things that determine whether a deck feels premium or generic: **what goes on the slide**, and **how it's designed**. Both matter equally — a beautifully designed slide full of generic claims is still a bad slide, and a slide with a killer stat in a templated layout undersells it.

Use this alongside whichever files are in this collection:

- **content-mining.md** — how to extract a deck's actual content from research, so it's grounded and specific instead of plausible-sounding filler
- **visual-design-principles.md** — how to make deliberate design choices instead of defaulting to the same three looks every AI-generated deck converges on
- **slide-craft.md** — practical, slide-by-slide guidance: what makes a headline land, how to pick a layout for a given piece of content, and what to cut

## The core discipline, in one sentence

**Every slide should contain something that could only be true of this specific company, this specific deal, this specific moment — not something you could paste into a competitor's deck unchanged.**

If a slide reads exactly the same after swapping "CETrace" for a generic competitor's name, it failed. If a bullet point could have been written without reading the research, it's filler. This applies as much to a slide's visual treatment as its words — a design choice made because it's the default is the visual equivalent of a generic bullet point.
