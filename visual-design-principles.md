# Visual Design Principles for Premium Decks

AI-generated visual design tends to converge on the same handful of looks regardless of subject matter: a dark background with one bright accent color, evenly-spaced icon-plus-headline cards in a grid, the same rounded corners and drop shadows on everything, gradient text on big numbers. None of this is wrong in isolation — the problem is when it's the default rather than a choice made for this specific deck, this specific brand, this specific audience.

## Make the palette and type do real work

Goenvi's brand is a deep forest green and warm gold — use that consistently, but within it still make deliberate choices per slide type rather than treating every slide as a palette swap of the same template. A cover slide, a hard-numbers slide, and a competitive-comparison slide are different *jobs* — they can share a palette while looking meaningfully different in structure and emphasis.

Typography should carry hierarchy through actual weight and size contrast, not through color alone. A slide where the headline and body text differ only in color, at the same size and weight, reads as flat regardless of how good the palette is. Pick a genuine display/body pairing and commit to it — don't default to one weight of one font for everything.

## Every visual element should encode real information, not decorate

A numbered step sequence is correct when the content genuinely has an order — a rollout phased over months, a workflow with real sequence dependency. It's wrong when it's applied to four features that have no real order, just because numbered circles look organized. Before adding a number, ask whether removing it would lose real information (order, sequence, priority) or just remove a decorative device.

The same discipline applies to icons, dividers, and card-based layouts: they should be doing structural work (this is a group, this is a boundary, this is a sequence) rather than filling space. A slide with four evenly-sized cards because there happen to be four bullet points is a weaker choice than a layout that reflects the actual relationship between those four things — are they equally weighted, or does one matter more? Is there a hierarchy the layout should show?

## Restraint over maximalism, but not blandness

The instinct to add visual interest to every slide — gradients, glow effects, decorative shapes in every corner — usually reads as trying too hard rather than as premium. Real premium design spends its visual boldness in one or two deliberate places per deck (a striking cover, one genuinely arresting big-number moment) and stays disciplined everywhere else. A deck where every single slide has a dramatic gradient and a floating shape reads as noisy, not sophisticated. Quiet slides make the bold ones land harder.

## Avoid the specific tells of templated AI output

Watch for these patterns, since they're common defaults rather than considered choices: identical card layouts repeated for every list regardless of what the list actually contains; emoji used as visual bullets or section markers in a business document (they read as informal, not premium, in this context); centered text as the default alignment for body copy (left-aligned reads more confidently for anything beyond a single short line); a color accent applied uniformly with no variation in how it's used across slide types.

## The test before finalizing a slide's design

Would this slide's layout choice make sense if you didn't know what content was going into it, or did the layout get picked specifically because of what this slide needs to communicate? A big-stat layout exists because one number is the most important thing on that slide — not because "some slides should be big-stat layouts for variety." If a layout was chosen for variety's sake rather than because the content demands it, reconsider it.
